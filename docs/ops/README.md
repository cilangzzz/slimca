## 使用纪律

1. **本目录全部内容为内部底稿，不构成法律意见**；登记/备案/上架要求一律以官方渠道（登记机构、主管部门、各应用商店）当期公示为准；法规相关文件不得虚构条文、不解读义务，一切以官方文本与咨询结论为准。
2. **「待人工复核」「待定」标记项**在提交/执行前必须逐项确认回填；关键登记字段（名称/主体/日期）定稿后同步更新全部材料保持口径一致。
3. **「待用户凭据」标记项**：Supabase 项目凭据尚未提供，真实端点联调全部按配置注入设计（与 AI 配置同模式的 `--dart-define` 编译期注入，Key 不入仓库）；凭据到位前本地链路验证用 `LocalLoopbackBackend` 缺省装配（§6.1）。
4. **材料提交凭证归档**（§3.9 验收）：软著与备案的提交凭证、受理通知、咨询纪要随提交当日归档；归档位置待定（建议私密目录、不入公开仓库，待人工复核）。
5. 单元/契约测试禁止真实网络：同步相关验收一律使用 `InMemorySyncBackend` / `LocalLoopbackBackend` Fake 远端（§6.7 验收自动化纪律）。

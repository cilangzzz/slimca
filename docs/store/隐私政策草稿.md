# Slimca 隐私政策

**生效日期：【待人工复核：定稿日】｜版本：v1.0**
**运营者主体：【待账号：开发者/公司主体名称】（下称「我们」）**
**联系方式：【待账号：隐私事务联系邮箱】**

Slimca（下称「本应用」）是一款本地优先的个人生活记录应用：记一件事，钱和卡路里一起入账。我们在设计上以「数据存留在你手中」为第一原则。请在使用前阅读本政策；开始使用即表示你已理解并同意本政策所述的数据处理方式。

## 一、本地优先架构（数据存在哪里）

1. **全量本地存储**：你的全部记录数据首先保存在你设备的本地数据库中；**无网络时，全部功能可用**（飞行模式全流程支持）。[设计依据 §3.7 本地优先 P0]
2. **派生数据永不上云**：统计、汇总、当日结余、AI 解析留痕等派生数据仅存于你的设备本地，不参与同步。[设计依据 §6.1 原则]
3. **同步为可选功能**：仅当你主动注册/登录账号并开启同步时，同步范围内数据（见第四节）才会经加密通道存储于我们的云端服务（【待账号：云端服务提供方及地区，如 Supabase 托管实例】）；你可在设置中查看同步状态、管理已登录设备。[设计依据 §3.7]
4. **端到端加密为规划项**：当前版本采用传输加密+账号隔离；端到端加密（云端只见密文）为后续版本规划功能，上线前我们会更新本政策。[设计依据 §6.6 P2]

## 二、数据类别

本应用处理的数据仅限以下类别（均由你主动输入或产生）：

| 类别 | 内容 | 默认存储位置 |
|---|---|---|
| 热量数据 | 记录事件标题、菜品、份量、热量值、宏量营养、AI 置信度 | 本地；开启同步后随账号同步 |
| 金额数据 | 收支金额、分类、备注、标签、账本、修正记录 | 本地；开启同步后随账号同步 |
| 健身数据 | 运动时长、类型、按 MET 表估算的消耗热量、体重档案（仅作估算参数） | 本地；开启同步后随账号同步 |
| 计划数据 | 待办事项与完成状态 | 本地；开启同步后随账号同步 |
| 账号信息 | 注册/登录所需的邮箱、用户标识 | 云端账号系统（仅开启同步时产生） |
| 设备信息 | 用于同步的设备标识与注册信息 | 本地；开启同步后随账号登记 |
| 诊断信息 | 崩溃日志、性能数据、匿名的功能使用统计（如录入漏斗） | 【待人工复核：随监控供应商定版后如实列明收集项、目的与留存期】 |
| 文字输入原文 | 见第三节 AI 处理边界 | **默认不上云** |

本应用**不申请、不收集**：精确位置、通讯录、短信、通话记录、广告标识符；**不含广告 SDK**；照片原图（拍照通道上线后）**不落服务端**（见第三节）。

## 三、AI 处理边界

1. **用途与机制**：当你使用文字/语音录入时，输入内容会被发送至大语言模型服务，以解析出热量与金额等结构化字段初值；解析结果先交由你确认或修正后才写入你的记录，AI 不会直接替你入账，生成内容不会自动对外发布。[设计依据 §7.1]
2. **文字原文默认不上云（raw_input 开关默认关）**：默认状态下，你的输入原文仅在本次解析请求中临时使用、用后即焚，不落云端存储；我们仅在你设备本地保留结构化解析结果与置信度供你排查。你可在设置中主动开启「原文留档」以便排查，该开关随时可关。[设计依据 §3.3 raw_input 上云开关 P0；开关开启后的云端留档范围与期限以实现定版为准，【待人工复核】发布前如实更新本条]
3. **可关闭**：AI 解析完全可选——解析失败或超时会自动降级为手填表单，输入功能永不因 AI 不可用而受阻；断网时记录进入本地草稿队列，联网后可自动补解析。[设计依据 §7.4]
4. **第三方服务如实列明**：解析调用以下第三方 API（名单可能随可用性调整，我们会在本政策与设置页保持一致更新）：
   - 文本解析：【待人工复核/待账号：主用供应商与模型如实列明，如 GPT-4o-mini（境外通道）、Qwen（阿里云）、GLM（智谱）——以 W7-8 合规咨询结论（docs/ops/算法备案材料.md §2.3）定稿为准】；
   - 语音转写：优先在你的设备本地完成（系统端侧语音识别）；仅当端侧识别不可用时，【待人工复核：云兜底是否启用及供应商】音频仅用于本次转写、用后即焚；
   - 拍照识别（该功能为后续版本规划）：照片将压缩后仅用于本次识别，**原图不落服务端、解析后即焚**；该功能上线前我们会先更新本政策与本表。
5. **供应商角色**：上述第三方仅作为受托处理方为本次功能服务；我们不出售你的数据。

## 四、同步、导出与删除权

1. **同步范围明示**：开启同步后，仅上述「本地；开启同步后随账号同步」类别的明细记录经加密通道同步；派生数据（统计/结余/解析留痕等）不上云。同步失败仅作状态提示，不阻塞任何操作。[设计依据 §3.7/§6.1]
2. **全量导出**：你可随时在「设置 → 导出」将全部数据（含明细与修正历史）导出为 JSON/CSV。[设计依据 §3.7 数据主权 P0]
3. **一键清空**：你可随时一键清空本地全部数据；同步用户还可删除云端账号数据。【待账号：账号注销入口与云端数据删除时限——按账号系统实际能力如实写明】
4. **迁移权**：同步服务支持整体导出迁移方案（自托管选项为规划项），你的数据不锁定在我们平台。[设计依据 §6.1 P2]
5. **主体权利**：你有权访问、更正、删除你的数据，可撤回同意（关闭同步、关闭原文留档、一键清空），可通过第一节联系方式行使上述权利。我们将在【待人工复核：承诺时限】内响应。

## 五、免医疗与免财务建议声明

1. **热量与消耗均为估算值**：AI 解析结果基于通用食物数据估算并标注置信度，运动消耗按 MET 表估算并按 **±20% 口径**在界面明示。以上数值**仅供参考，不构成医疗、营养诊断或治疗建议**，本应用不提供任何诊疗功能；如有健康或疾病问题，请咨询专业医师或机构。[设计依据 §11.3「不做医疗建议」口径、§3.5 ±20% 口径]
2. **本应用仅做收支记录**，不构成投资、理财或税务建议。

## 六、未成年人

本应用面向一般用户，不针对儿童设计，不主动收集未成年人信息。若监护人发现未成年人未经同意使用并提供信息，可联系我们删除。

## 七、政策更新

我们可能随功能变化更新本政策（新增功能类别、供应商调整、端到端加密上线等），重大变更将在应用内显著提示并更新生效日期；历史版本可通过第一节联系方式索取。
